Thank you for using PDF Toolkit!

--------------------------------------------------------------------------------
                    IMPORTANT: GHOSTSCRIPT INSTALLATION
--------------------------------------------------------------------------------

For FULL PDF compression functionality (30-90% file size reduction), you need
to install Ghostscript. Without it, compression will have limited effectiveness.

DOWNLOAD GHOSTSCRIPT (FREE):
  https://ghostscript.com/releases/gsdnld.html

INSTALLATION STEPS:
  1. Download the 64-bit AGPL Release for Windows
  2. Run the installer with default settings
  3. Restart PDF Toolkit after installation

VERIFICATION:
  Open Command Prompt and type: gswin64c -version
  If installed correctly, you'll see the version information.

--------------------------------------------------------------------------------
                         COMPRESSION LEVELS
--------------------------------------------------------------------------------

When Ghostscript is installed, these compression settings are available:

  Level     | Image DPI | JPEG Quality | Best For
  ----------+-----------+--------------+-----------------------------
  Low       | 200 DPI   | 85%          | High-quality printing
  Medium    | 150 DPI   | 70%          | General use, email sharing
  High      | 100 DPI   | 50%          | Web uploads, archiving
  Extreme   | 72 DPI    | 30%          | Maximum compression, preview

--------------------------------------------------------------------------------
